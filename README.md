# LearnHub – Online Courses Platform

LearnHub is a modern online learning platform designed to help users discover, explore, and learn from high-quality courses. The project focuses on clean UI, scalability, and an excellent user experience, built with a modern frontend stack.

---

## 🚀 Features

* Browse and explore online courses
* Clean, modern UI using **shadcn/ui** and **Radix UI**
* Fully responsive design (mobile, tablet, desktop)
* Smooth animations and interactive components
* Form handling with validation
* SEO-friendly meta tags with Open Graph support
* Fast performance powered by Vite

---

## 🛠️ Tech Stack

* **Framework:** React 18 + TypeScript
* **Routing:** React Router DOM
* **UI Components:** shadcn/ui, Radix UI
* **Styling:** Tailwind CSS, tailwindcss-animate
* **Forms & Validation:** React Hook Form, Zod
* **State & Data Fetching:** TanStack React Query
* **Charts:** Recharts
* **Icons:** Lucide React
* **Build Tool:** Vite
* **Linting:** ESLint
* **Deployment:** Vercel

---

## 📦 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/ahmedismai/LearnHub.git``bash
cd learnhub
```

Install dependencies:

```bash
npm install
```

Run the project locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

The app will run on:

```
http://localhost:5173
```
